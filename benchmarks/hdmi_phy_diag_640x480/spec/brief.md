Build a temporary static HDMI diagnostic for the HX1P35A. Keep the verified 640x480 timing, PH1P PLL, TMDS encoder, DDRX5 serializer, differential output buffers, board pin assignments, and HDMI power enable. Replace only the cube geometry and framebuffers with eight vertical RGB color bars. This project is for isolating the video core from the board-level HDMI PHY and must not alter the original cube project.
