# IC Forge v0.4.2

## 修复

- 为 OpenAI-compatible API 请求加入明确的 `ICForge/<version>` User-Agent。部分 Cloudflare 前置服务会把 Python 默认 `urllib` 标识作为浏览器签名拒绝，并返回 HTTP 403 / error 1010。
- 补充 Chat Completions 接口选择说明：只提供 `/v1/chat/completions` 的服务需选择 `chat` provider；`api` provider 请求的是 `/v1/responses`。

## 验证

- 通过兼容端点的 DeepSeek 模型完成 Chat Completions 结构化 JSON 请求，解析结果为合法 JSON 对象。
- 通过 `git diff --check`。
