# IC Forge v0.4.4

## 修复

- `/connect` 表单改为内部滚动，取消和保存操作固定在弹窗底部。
- 输入框 Enter 与 Ctrl+Enter 保存；Esc 取消。全局 Esc 不再抢先拦截弹窗的取消操作。
- Chat Completions 使用 JSON Object 模式，并把输出 schema 放入提示词，兼容只实现 JSON Mode 的 OpenAI 兼容服务（包括 DeepSeek Chat Completions）。
- HTTP 5xx 错误会显示接口类型和服务端请求标识（若服务端提供），便于与 API 后台日志对应。

DeepSeek Chat Completions 的 `response_format` 支持范围见[官方 API 文档](https://api-docs.deepseek.com/api/create-chat-completion/)。
