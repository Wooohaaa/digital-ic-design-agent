# IC Forge v0.4.3

## 新增

- 增加九套纯黑底主题：Forge Gold、Rose Milk、Citrine Grove、Nord Frost、Tokyo Night、Catppuccin Mocha、Catppuccin Latte、Carbon Mint、Cobalt Signal。
- 增加四种终端字标：Block Forge、Isometric 3D ASCII、Pixel Glitch、Minimal。
- 新增 `/theme` 与 `/logo` 选择菜单和直接切换命令；两种偏好按工作区保存。
- 保持界面各区域纯黑底，主题只更换文字、字标、光标和线框色。

## 参考

- 用户提供的 Rose 与 Citrine 配色图。
- Nord、Tokyo Night、Catppuccin 官方公开调色板；色值映射按纯黑终端背景重新调整。

- 截图检查 128×40 与 80×24 终端布局、三种主题和多个字标。
