# 两槽 FIFO 的独立规格证明

2026-11-22：新增[公共规格验收入口](spec-acceptance.md)，已在同一 FIFO 和 8 位计数器上验证。本页保留 2026-11-20 的专用脚本与证据复现。

这一项检查共享 `fpga_agent/templates/conformance/rtl_fifo/fifo_two.sv` 是否实现独立队列规格。[同源综合网表 LEC](fifo-flow.md)单独检查综合是否保持 RTL 行为。SV/UVM 仿真用例与版本仍为 v0.14。

首次低有效同步复位边沿之前，寄存器可处于任意二值状态；第一个边沿采样到复位有效。此后每拍的复位、输入 valid、输出 ready 和全部 16 位输入可以任意变化。FIFO 只有一个上升沿时钟。规格要求按边沿前占用判断允许的传输：满时不能写、空时不能读、部分占用时可以同拍出入；复位优先于两端传输，空队列输出数据为零。

参考实现用有序列表保存队首与后项，不采用 DUT 的环形指针。Yosys 只暴露 DUT 的观察端口，任何参考信号都不驱动内部状态。证明关系要求占用量一致且不超过二，读写指针只在占用一槽时不同，两条有效数据按队列顺序对应；无效槽不受约束。证明脚本检查展开后只有一个上升沿时钟，没有初始寄存器约束、额外形式假设或不支持的单元。

三个 SAT 任务分别检查：

1. **复位基例**：第一拍复位有效，从不受约束的初态出发，第二拍已满足关系和端口规格。
2. **单步保持**：第一拍满足关系，所有输入任意，第二拍仍满足关系。
3. **端口性质**：关系成立即推出 `in_ready`、`out_valid` 和 `out_word` 等于规格。

基例加单步保持给出任意周期数的结论。两拍是单步证明编码的长度，不是行为保证的周期上限。额外求出空、一槽、满的复位后可达轨迹。复位被写入抢占、满时同拍错误写入、读错队首槽三种变异各自触发对应的 SAT 义务失败，同时保留从首次复位出发、五拍内可重现的端口反例。这些有限反例不限定正向证明。命令参数可查 [Yosys SAT 文档](https://yosyshq.readthedocs.io/projects/yosys/en/latest/cmd/index_formal.html#sat-solve-a-sat-problem-in-the-circuit)。

```powershell
$env:PYTHONPATH = (Get-Location).Path
python scripts/prove_fifo_spec.py --output reports/fifo-spec
```

输出目录须为新目录，运行产物包括 DUT/规格快照、模型、逐项脚本和日志、见证、以及绑定 SHA-256 的 `result.json`。本机使用 Yosys 0.71。范围限此两槽同步 FIFO 的二值时序安全性质；未证明复位前行为、四态传播、环境最终会接收数据或物理时序。
