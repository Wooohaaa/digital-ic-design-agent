# Anlogic TD

`generated_flow.tcl` is generated by `fpga-agent td` from the trusted local manifest. The flow creates an Anlogic project for PH1P35MDG324, adds RTL and board constraints, runs synthesis, and optionally runs place/route. The agent does not execute Tcl returned by the model.

TD reports and `.bit` output are created under this directory by the installed TD version. Inspect timing and resource reports before using BitWriter.
